    对战条款¶

    总纲：对战使用的是100级6V6单打和100级6选4双打（含R键对战预览）¶

    一、道具条款及其不可共存条款¶

    1. 禁止使用光粉,悠闲薰香

    2. 连续攻击特性的宝可梦不能携带王者之证和锐利之牙

    3. 对战使用厚底靴仅一只宝可梦并且不能是多重鳞片快龙和火神蛾

    4. 向日花怪烧焦的种子道具和青草疾行特性共存时候，禁止使用生长，烈咬陆鲨和快龙携带机变骰子时，禁止使用鳞射

    5. 勿花果，异奇果，芒芒果，乐芭果，芭亚果这五种回复1/2HP的树果一场战斗中仅仅可携带俩个，战术背心只能携带一个

    二、招式条款:挥指技能抽到不算¶

    1. 禁止使用接力技能接能力变化（对面让你增加不算）

    2. 禁止使用一击必杀技能。

    3. 不可使用增加闪避能力的技能（点穴抽到的不算）

    4. 酋雷姆禁止使用龙舞和冷冻干燥，克雷色利亚禁止使用自我再生，凯路迪欧禁止冰冻光束

    5. 图图犬可以写生出1-649宝可梦的招式，其他的就无法写生

    三、宝可梦种族条例¶

    1. 禁止使用种族值600以上（不含600）除请假王，雷吉奇卡斯，酋雷姆的宝可梦

    2. 禁止使用下列宝可梦：谢米天空形态、达克莱伊、代欧奇西斯（速度，攻击，一般），盖诺赛克特，龙卷云灵兽形态，加速火焰鸡

    3. 美洛耶塔携带旋律音符且没有古老之歌招式时即可保证舞步形态

    四、特性条例:¶

    1. 踩影特性禁止

    2. 心情不定特性禁止

    3. 土地云化身形态强行特性禁止

    五、其他条例¶

    1. 禁止使用全国图鉴编号相同的两只pm，禁止携带非健康的pm

    2. 禁止在联机过程中使用金手指，禁止使用努力值值总和超出508的宝可梦

    3. 睡眠条款：已经内置在游戏里，条款与Pokemonshowdown一样(64双打没有）
